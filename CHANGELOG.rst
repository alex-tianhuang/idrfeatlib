Changelog
=========

v0.0.0 (2026-10-18)
-------------------

Before any changelog notes were taken, this library had the following functionality:
- Compute features, including composition, motifs, patterning, etc.
- Compute mean and standard deviation of those features for weights
- Do feature mimic design
- Compute feature distances

v0.0.1 (2026-10-18)
-------------------

Switched behaviour of simple spacing and kappa on invalid composition profiles.
Previously it would throw an error, now it returns 0.
